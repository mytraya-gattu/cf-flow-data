# Fig. 7: pair-correlation function

Pair-correlation function `g(r)` of the uniform FQH ground states at nu = 1/3 (N = 24) and nu = 2/5 (N = 26) as a function of the electron separation `r`, for a range of `kappa` (Monte Carlo).

## Files
- `pair_correlation_function_N24_nu1_3.csv`
- `pair_correlation_function_N26_nu2_5.csv`

## Columns
1. `row_iter`: row index
2. `kappa`: Landau-level mixing strength
3. `r`: electron separation, in units of `lB` (bin center)
4. `g_r`: `g(r)`
5. `g_r_err`: Monte Carlo standard error of `g(r)`
